# 평가지표들

## 분류 모델
이진 분류 모델 : 0과 1사이의 확률값 예측 ➔ 임계값 (Threshold) 을 기준으로 0, 1을 분류


## Confusion matrix (혼동 행렬)
- TN (True Negative)  | FN (False Negative)
- FP (False Positive) |	TP (True Positive)

### Recall(재현율_Sensitive _TPR)
-  실제 True인 것 중에서 모델이 True라고 예측한 것의 비율
- TP / (TP + FN)
- Negative로 예측했을 때 리스크가 큰 업무에서 중요하게 여겨짐   
**즉 FN의 리스크 > FP의 리스크**   
EX) 금융 사기, 암 예측 등등 
- 실제 데이터(DATA)의 관점에서 정답을 정답으로 맞춘 경우

### Precision(정확도/정밀도)
- Precision = TP / (FP+TP)
- positive로 예측한 것들 중에 실제 Positive의 비율(TP) 
- 모델의 관점에서 정답을 정답으로 맞춘 경우 
- 즉 POSITVE의 정답률 PPV(Positive Predictive Value)

### FPR [FP / (FP+TN)]
실제 Negative 샘플 (FP+TN) 중 Positive (FP)로 잘못 예측한 비율  정상 샘플을 이상 샘플로 잘못 예측함으로써 조치 및 기회비용이 발생하므로 , 문제에 따라 허용할 수 있는 오차 범위를 결정할 때 사용

## ROC-AUC
대표적인 분류모델의 평가지표

### ROC Curve 
- x축(Fallout) : 실제 False인 data 중에서 모델이 True로 분류한 비율 (False Positive Rate)
- y축(recall) : 실제 True인 data 중에서 모델이 True로 분류한 비율
- 해석 : curve가 왼쪽 위 모서리에 가까워질 수록 성능이 좋다.  
- 즉 recall이 크고, fallout이 작을 수록 좋다. 

### AUC (Area Under Curve)
ROC 커브가 그래프이기 때문에 수치 비교가 어려움 ➔ 그래프 아래의 면적값을 이용함. = AUC(Area Under Curve)입니다. 최대값은 1이며 좋은 모델(즉, Fall-out에 비해 Recall 값이 클수록) 1에 가까운 값이 나옵니다.
